aplicativo mobile usando react native que consome uma api jwt , o sistema pode cadastrar usuarios e fazer login onde serao redirecionados para uma pagina home onde serao exibida todas as acoes e suas infos, o usuario pode comprar as acoes nessa pagina, existe tbm pagina de saque, deposito, carteira(onde o usuario pode ver suas acoes e vende-las), dashboard(onde usuario pode ver um grafico com todas suas acoes) e logout.
